# jkzhou.ca

Personal portfolio website for photography, videography, and creative projects.

Website: https://jkzhou.ca

## what did I do?

- used next.js framework to program the site
- added a photos, videos, and contact page
- contact page uses resend API
- media is hosted on an R2 cloudfare bucket for quick and easy access
- samba server on my home server to sync to the R2 bucket
- CI/CD on my homelab to host the website using github actions
- used github container registry for docker image hosting
- learned how to use cloudfare and DNS to host my own website
- learned how to use portainer to manage docker and use docker compose
- installed a reverse proxy (nginx proxy manager) to manage SSL certificates and route within my local server
